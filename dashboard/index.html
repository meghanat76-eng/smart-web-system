ADSA • OOPJ • Python

1. ADSA – Unit 2 (Graph Theory & Divide and Conquer)

Grid modelled as an undirected graph G = (V, E) with Adjacency Matrix and Adjacency List. Divide-and-Conquer bipartitions the 8 zones into North (A, B, C, D) and South (E, F, G, H) clusters to reduce cross-sector transmission bottlenecks.

2. OOPJ (Java Object-Oriented Simulation)

Encapsulated entities: Grid, Zone, Substation, Connection, LoadData, LoadTransfer, LoadBalancer. Demonstrates Abstraction (GridEntity), Inheritance, Polymorphism (status logic), and custom Exception handling.

3. Python (Data Processing & Forecasting)

Reads CSV data, computes Exponential Weighted Moving Average (EWMA) and linear trend extrapolation to predict load spikes before thermal limits are reached.
